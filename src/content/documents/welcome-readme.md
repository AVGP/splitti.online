===================================================================
                WELCOME TO SPLITTI OS 98
===================================================================

Thank you for exploring this retro 11ty web desktop experience!

FEATURES INCLUDED:
- Fully dynamic folder collections ("My Photos", "My Diary", "My Documents")
- Live Splitti OS 98 Taskbar with system clock & date
- Flashing dual-monitor Network Tray Icon (sending/receiving data)
- Splitti OS File Explorer & Notepad markdown reader
- Responsive mobile support: windows maximize & stack cleanly on mobile screens!
- Clean Seagreen background wallpaper (`#008080`)

TIPS:
* Double-click (or tap on mobile) any folder icon to explore its contents.
* Click Start button to access system options.
* Drag window titlebars to move them around on desktop viewports.

Enjoy your trip back to 1998!
